# XeniumAlign

Toolkit for registering Xenium and post-Xenium images (mIF, H&E).

## Documentation

Check [XeniumAlign documentation](https://leohermet1.github.io/xenium_align/) to get started. It contains installation explanations and tutorials.

## Installation

`XeniumAlign` requires Python `>=3.11`.

You can create a dedicated environment using [mamba](https://mamba.readthedocs.io/):

```bash
# Create the environment from environment.yml
mamba env create -f environment.yml
# Activate it
mamba activate xenium_align
```
